## Boundaries and host responsibilities

- Catalogs, interactions and event kinds are explicit module registrations. Logging belongs to the core. Startup checks the capability/handler graph. Host-owned authorization runs on every operation; catalog visibility distinguishes method and identifier.
- The provided continuation/task store is bounded and in memory. Its state does not survive process restart or automatically span replicas. Supply a bounded executor and handle deployment/routing according to that lifetime. Accepted responses are limited to 256 KiB and a task to 256 distinct input keys.
- Cancellation is cooperative and cannot undo committed effects. Expired tasks become inaccessible and are interrupted; their capacity remains charged until their runner exits. Host authentication, incoming HTTP and upstream clients need host network timeouts.
- External schema references are denied. RE2/J patterns are bounded at 4,096 characters; unsupported ECMAScript lookaround/backreference constructs fail registration. Resource-template matching is explicitly host-owned.
- The anonymous conformance profile, fixture identities, reset routes and mutable test state remain sample-only. Production libraries contain none of those fixtures.
- Stdio, client-role behavior, MCP Apps, legacy initialization and actual saas-boilerplate/ToastMCP adoption were outside the reported HTTP server gaps and were not implemented or exercised.
- Javadoc builds retain missing-comment warnings. Verification did not publish packages, deploy a service or migrate a product. Project-owned code is licensed under the [MIT License](../LICENSE).
